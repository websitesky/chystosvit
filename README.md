# ЧистоСвіт — перший екран

Перший екран сайту клінінгової компанії «ЧистоСвіт» (Івано-Франківськ).
Відео на всю ширину, офер, дві кнопки. Далі переноситься у Weblium.

## Запуск

```bash
node scripts/serve.js
```

Далі відкрити http://localhost:5178

Через `file://` теж відкривається, але браузер кешує CSS і плутає
підвантаження Google Fonts — для перевірки верстки користуйся сервером.

## Структура

```
index.html            окремий сайт
weblium-embed.html    той самий екран одним шматком для HTML-блока Weblium
css/base.css          ресет; у Weblium НЕ переносити
css/styles.css        весь екран, класи під префіксом .cs-
assets/video/hero.mp4 фонове відео
assets/img/           постер
scripts/serve.js      локальний статичний сервер для розробки
docs/README.md        детальна документація, тексти, що лишилось зробити
docs/variants-tagline.html   варіанти оформлення слогана
```

Повна документація — [docs/README.md](docs/README.md).
