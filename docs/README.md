# ЧистоСвіт — перший екран

## Файли

```
chystosvit/
├─ index.html              ← окремий сайт (робоча версія)
├─ weblium-embed.html      ← той самий екран одним шматком для HTML-блока Weblium
├─ css/
│  ├─ base.css             ← ресет; у Weblium НЕ переносити
│  └─ styles.css           ← весь екран, класи під префіксом .cs-
├─ assets/
│  ├─ video/hero.mp4       ← фонове відео
│  └─ img/hero-poster.jpg  ← тимчасовий стоковий постер, замінити
└─ docs/README.md
```

Відкрити `index.html` у браузері.

## Тексти першого екрана

Порядок зверху вниз: заголовок → слоган → акцентний рядок → буліти → кнопки.

| Елемент | Текст |
|---|---|
| H1 | Клінінгові послуги в Івано-Франківську для квартир, будинків та бізнесу |
| Слоган | ШВИДКО. НАДІЙНО. ОХАЙНО |
| Акцентний рядок | Приберемо так, щоб ви сказали ВАУ |
| Буліти 2×2 | Оперативність та швидкість · Прозорі та доступні ціни · Свої засоби та обладнання · Гарантія результату |
| CTA основна | Замовити прибирання → `#order` |
| CTA другорядна | Дізнатися вартість → `#prices` |

Обидві кнопки ведуть на якорі `#order` і `#prices` — блоків ще немає.

Слоган зроблено приглушено-білим, а не рожевим: акцент віддано рядку
«Приберемо так…», два рожевих рядки поспіль зливались в одну пляму.

Контраст рожевого акцентного рядка виміряно на реальних кадрах відео —
**3.8–3.9:1**. При 28 px жирного шрифту поріг WCAG для великого тексту 3:1,
тобто рядок проходить. Якщо колись зменшувати його кегль нижче 18.66 px —
поріг стане 4.5:1 і рожевий перестане проходити.

## Що зроблено

- Відео на всю ширину екрана, `autoplay muted loop playsinline`, постер як фолбек.
- Затемнення у два градієнти: зліва направо під текст, згори вниз — щоб кнопки
  й буліти лягли на темне, як у макеті.
- Кнопка паузи відео праворуч. Це не декор: WCAG 2.2.2 вимагає, щоб контент, який
  рухається довше 5 секунд, можна було зупинити. При `prefers-reduced-motion`
  відео ставиться на паузу одразу.
- Перевірено на 390 / 768 / 1280 / 1920: горизонтального скролу немає, екран рівно
  у висоту вікна, весь текст вміщується без прокрутки, кнопка паузи ні з чим не
  перетинається. Буліти 2×2 на десктопі й планшеті, в один стовпець на мобільному.
- На мобільному кнопка в хедері ховається, а телефон стає рожевою пігулкою
  з тап-таргетом 46 px — дзвінок там цінніший за перехід до форми.

## Відео

Зараз стоїть файл із 01.08: **1088×692, 24 fps, 4,6 с, 4,5 МБ** (≈7500 kbps).

Дві проблеми, обидві варто закрити перед публікацією:

1. **Замалий кадр.** На екрані 1920 px відео розтягується в 1,76 раза понад
   рідний розмір — на десктопі буде помітно м'яко. Треба вихідник від 1920 px завширшки.
2. **Завеликий бітрейт.** 7500 kbps для такого кадру — надлишок. Стискається
   приблизно до 1 МБ без видимої втрати. Перший екран на 4,5 МБ помітно гальмує
   завантаження, а це прямо б'є по конверсії.

ffmpeg у системі немає, тому перестиснути я не можу. Команда, коли він з'явиться:

```bash
ffmpeg -i input.mp4 -t 5 -an -vf "scale=1920:-2,fps=25" -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 27 -movflags +faststart assets/video/hero.mp4
```

Постер із першого кадру (щоб постер і відео збігались):

```bash
ffmpeg -i assets/video/hero.mp4 -ss 0.5 -frames:v 1 -q:v 3 assets/img/hero-poster.jpg
```

Цільові вимоги: 1920×1080, H.264, `yuv420p`, без аудіодоріжки, 3–5 с, безшовний
цикл, до 3 МБ.

`assets/img/hero-poster.jpg` зараз — **стокове фото** (жовті рукавички, блакитна
сорочка), не бренд. Обов'язково замінити кадром із самого відео.

## Що треба підтвердити з клієнтом

| Що | Ризик |
|---|---|
| Буліти «Оперативність та швидкість», «Прозорі та доступні ціни», «Гарантія результату» | Це оціночні судження без фактів — рівно те, що правило конкретності забороняє («7 років на ринку» замість «великий досвід»). Працюватимуть значно сильніше як цифри: строк виїзду, діапазон цін, умови гарантії. |
| «Гарантія результату» | Потрібні умови: що саме і в який строк переробляється безкоштовно. Інакше це порожня обіцянка. |
| Постер і відео | Замінити стоковий постер, підняти роздільність відео. |

## Перенесення у Weblium

1. Завантажити `hero.mp4` і `hero-poster.jpg` у медіатеку Weblium, скопіювати їхні URL.
2. Додати на сторінку блок **HTML-код**.
3. Вставити туди **весь** вміст `weblium-embed.html`.
4. Замінити в коді `assets/video/hero.mp4` і `assets/img/hero-poster.jpg` на URL з кроку 1.
5. Якщо в Weblium уже налаштований власний хедер — видалити секцію `<header class="cs-header">`.

Чому саме так зроблено:

- усі класи мають префікс `.cs-` і живуть усередині `.cs-scope` — стилі конструктора
  не переб'ють екран, і екран не зіпсує сусідні блоки;
- скид написаний через `:where()`, тобто з нульовою специфічністю. Звичайний
  `.cs-scope h1 { margin: 0 }` має специфічність (0,1,1) і перебиває
  `.cs-hero__title` (0,1,0) — через це всі відступи в блоці гасли;
- у `weblium-embed.html` немає глобальних селекторів (`html`, `body`, `*`) — вони
  винесені в `css/base.css`, який у Weblium не переноситься;
- шрифти підключені через `@import` усередині `<style>`, бо конструктор може
  вирізати `<link>` з голови документа;
- `position: fixed` не використовується — у вкладеному блоці він поводиться непередбачувано.

**Важливо:** `weblium-embed.html` — це копія `index.html` + `css/styles.css`.
Після правок в основних файлах його треба перезібрати, інакше версії розійдуться.
